Intent goes in. Native feature trees come out.

DATUM never generates geometry. It plans a list of typed parametric operations, shows you exactly what they resolve to, and lets SOLIDWORKS execute them through its own API — so the tree is real, the design intent is real, and you can edit it by hand afterwards like anything else you modelled.

The whole deterministic core is free and runs offline. The model is an accelerant, not the product.

Execution

Nothing mutates until step 7

The order is the safety model. Six read-only stages run before a single API call touches your model, which is what makes this safe to hand to someone who doesn't trust AI yet.

01
Context
Tree, params, selection→PIDs, PDM lock, standards
02
Plan
Grammar-constrained ops stream into the card
03
Validate
Schema, DAG, policy, units
04
Resolve
Every PID and query resolved read-only
05
Preview
Targets highlighted in the live viewport
06
Dry run
Scratch copy, auto for destructive plans
07
Apply
One undo scope, graphics suspended
08
Verify
Errors, mass Δ, interference, lint Δ
09
Settle
Pass → log. Fail → auto-rollback
Read-only — cancel costs nothing Mutating — inside one undo group

Everything downstream of the planner is deterministic C# calling the SOLIDWORKS API. The model only authors the plan — so the executor, skills, batch, linter, drawings, and undo work with no model at all.

Operation IR v1.4

A closed vocabulary the model cannot escape

The planner emits typed operations from this list — never code, never raw API calls. It cannot invent an operation, so it cannot corrupt a model in a way we didn't anticipate. Plans are diffable, replayable, hand-editable, and shared by the AI path and the free deterministic path alike.

Realtime

What updates, from where, how fast

SOLIDWORKS notifications fire on the single-threaded apartment and must return in under a millisecond, so handlers only stamp a delta into a ring buffer. A background pump coalesces at 30 Hz and ships it over a named pipe to the WebSocket broadcast. If the stream stalls, every live element visibly desaturates — the UI never presents stale data as current.
